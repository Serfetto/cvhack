# План ML-программиста

**Цель роли.** Модели распознают людей и опасные объекты **на LinQ TPU**, сценарии надёжно ловят нарушения, а у нас есть честные цифры скорости и качества для защиты.

Основа: [ARCHITECTURE.md](../ARCHITECTURE.md) — разделы 1.2, 6, 7, 8. Общая шкала: [README.md](README.md).

## Зона ответственности

| Что | Где |
|---|---|
| Датасеты, свои ролики, разметка интервалов нарушений | `backend/ml/datasets/`, `data/eval/` |
| Обучение и дообучение YOLO | `backend/ml/training/` |
| Экспорт в ONNX, обрезка головы, квантование, компиляция `.tpu` | `backend/ml/export/`, `backend/ml/compile/` |
| Пре- и постпроцессинг (общие для CPU и TPU) | `backend/server/services/inference/ml_runtime/` |
| Бэкенды `onnx`, `pytpu`, `remote` и `tpu-worker` на стенде | `backend/server/services/inference/backends/` |
| Логика сценариев (`check()`), параметры и JSON Schema | `backend/server/services/analytics/scenarios/` |
| Бенчмарк и событийные метрики качества | `backend/ml/benchmark/`, `backend/ml/eval/` |

Каркас аналитики (трекинг, конечный автомат, реестр, очереди) пишет бэкендер. ML пишет только сами сценарии и подбирает пороги, включая параметры трекера.

## Приоритеты

- **MUST:** `yolov8n-pose` работает на TPU · сценарии `fall` и `immobile` · бенчмарк FPS и задержки
- **SHOULD:** модель `objects` на TPU · сценарии `proximity`, `running`, `phone` · событийные метрики на своих роликах
- **COULD:** `smoking` / `fire` · `fence` (перелезание) · классификатор действий по скелету

        "type": "object",
        "properties": {

        },
    }

    def check(self, track: Track, scene: Scene, params: dict) -> float:  # 0..1
        ...

## Подсказки

- **Вход статичный.** Batch фиксируется при компиляции; для b4 нужна отдельная программа.
- **Имена входов и выходов** берём из `meta.json`, не хардкодим.
- **Калибровка на случайных данных**, как в `compile.py` из SDK, сильно ухудшает INT8. Только реальные кадры.
- **Если O5 компилируется дольше 20 минут или падает** — сразу O1.
- **Компиляция и обучение** идут в фоне, пока пишется постпроцессинг и сценарии. Не ждать их впустую.

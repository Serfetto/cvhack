## Правила работы

- `main` всегда запускается командой `docker compose up`. Изменения — через короткие ветки `feat/*`, в `main` мержим после локального прогона.
- Не ломаем контракты молча: изменение `messages.py` или формата API обсуждаем в чате команды.
- Задача, которая блокирует другого человека, всегда важнее своей.
- Спим по очереди. Ночью делаем то, что никого не блокирует утром.

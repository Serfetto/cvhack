# План фронтенд-программиста

**Цель роли.** Каждая роль из кейса (охрана труда, мастер, диспетчер, юристы, руководство, ИТ) за пару кликов получает свой результат. Интерфейс отдельно оценивают по критерию UI/UX, и он же — главное, что эксперты увидят на демо.

Основа: [ARCHITECTURE.md](../ARCHITECTURE.md) — разделы 5.1, 5.3, 7.3, 9. Общая шкала: [README.md](README.md).

## Стек

React 18 + TypeScript + Vite · Ant Design 5 (`ru_RU`) · React Router · TanStack Query · Zustand · `openapi-typescript` + `openapi-fetch` (типы из Swagger бэкенда) · MSW (моки, пока нет API) · react-konva (редактор полигонов) · ECharts · hls.js · `@rjsf/antd` (формы параметров по JSON Schema) · dayjs.

## Экраны и кому они нужны

| Экран | Роли | Приоритет |
|---|---|---|
| Вход | все | MUST |
| **Лента событий** (realtime) | диспетчер, мастер | MUST |
| **Карточка события** | диспетчер, мастер, охрана труда, юристы | MUST |
| **Журнал** (фильтры, экспорт) | охрана труда, юристы | MUST |
| **Настройка камеры** (зоны + правила) | охрана труда | MUST |
| **Дашборд** | руководство, охрана труда | MUST |
| **Производительность** (FPS, задержки, камер на устройство) | ИТ | MUST — без неё нет замеров на LinQ |
| Камеры (живое видео) | диспетчер | SHOULD |
| Личный кабинет (профиль, подписки на уведомления) | все | SHOULD |
| Пользователи | админ | SHOULD |
| Мобильная лента для мастера в цеху | мастер | COULD |

Меню зависит от роли: мастер видит ленту и свои участки, руководитель — дашборд.

## Подсказки

- Генерировать типы из Swagger сервисов (`openapi-typescript http://…/openapi.json`). Ручные интерфейсы быстро разъедутся с бэкендом.
- Все координаты (рамки, полигоны) хранятся нормированными к 0..1. Перевод в пиксели — только при отрисовке по реальному размеру `<img>`.
- Цвета важности и названия сценариев держать в одном месте (`src/shared/severity.ts`, каталог `/scenarios`).
- WebSocket — один на приложение (Zustand-store), а не на каждый экран.
